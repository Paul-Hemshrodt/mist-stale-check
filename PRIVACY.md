# Privacy Policy — Mist Stale Check

_Last updated: August 24, 2026_

Mist Stale Check does not collect, store, or transmit any user data.

- **All processing happens locally in your browser.** The extension reads the
  URL of the Juniper Mist dashboard page you have open to identify which
  device or setting you are viewing, and compares API responses — entirely on
  your machine.
- **The only network requests it makes are read-only GET requests to Juniper
  Mist's own API** (`api.*.mist.com` / `api.*.mist-federal.com`), using your
  existing Mist session, on Mist domains you are already logged into. It
  never sends any other kind of request and never contacts any other host.
- **Nothing is ever sent to the extension's developer or any third party.**
  There are no analytics, no tracking, no telemetry, and no accounts.
- **The only thing the extension stores** is your chosen poll interval (a
  single number), kept in Chrome's extension storage and synced by Chrome
  across your own signed-in browsers. It contains no personal information.

If you have questions about this policy, open an issue on this repository.
